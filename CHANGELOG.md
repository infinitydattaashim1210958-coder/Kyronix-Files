## [1.0.0] — 2026-10-11

### Added
- Samsung My Files-style UI: bottom navigation, breadcrumb chips, list/grid toggle
- Full Android API 21–35 storage-permission handling
- MIUI HyperOS crash fixes (FileProvider, Settings intent fallback, NPE guards)
- Background directory loading via Kotlin coroutines
- Sort by name / date / size (asc + desc)
- Search / filter files by name
- Multi-select with long-press: rename, delete, share, open-with, properties
- Dark mode support
- Adaptive launcher icon
- Signed release APK + AAB via GitHub Actions CI/CD
